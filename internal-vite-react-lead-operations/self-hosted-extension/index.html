Install Callum Scout

Use this temporary Windows installation while the unlisted Chrome Web Store release is under review.

  1. 1

    Allow this Codeblix download location

    Download the plain-text registry file, open it, and approve the Windows prompts. Administrator permission is required.

    Download install policy
  2. 2

    Restart Chrome

    Close every Chrome window and open Chrome again. Before continuing, open chrome://policy and confirm ExtensionInstallSources contains https://extensions.codeblix.com/* with status OK.

  3. 3

    Add Callum Scout

    Chrome will show the extension permissions and ask you to confirm. If it says “Download suspicious file” instead, stop—the policy has not loaded correctly.

    Install Callum Scout

Expected Chrome message: Chrome may say “Managed by your organization” because the first file adds one Chrome installation policy. It does not install hidden software. To remove that policy later, download and open Remove-CallumScout-Policy.reg. When the Chrome Web Store release is approved, remove this self-hosted copy before installing the Store copy so both cannot run at once.
